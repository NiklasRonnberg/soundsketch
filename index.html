How to use Sound Sketch

Sound objects and recording

Click + to create a sound object. Give it a title, write an annotation, and use the × button in its upper-right corner to delete it.

Click Enable microphone before recording. A solid circle selects hold-to-record; a dotted circle selects click once to start and again to stop. An audio file can also be dropped onto the recording button.

When audio is ready, the button changes to Play and its duration is displayed. Drop an image into the annotation area. Double-click the image to edit the text annotation.

Canvas and selection

Use the mouse wheel to zoom and right-click and drag to pan. Left-click and drag on empty canvas to select several sound objects. Moving one selected object moves the selection. Copy and paste can duplicate selected sound objects.

Sequencing and mixing

Move sound objects close together to snap them. Horizontally snapped objects play sequentially from left to right. Press Play on any object to play the complete group.

Vertically snapped objects can overlap in time. Their horizontal offset within the vertical connection determines when they start relative to one another, so they can be layered and mixed. Horizontal sequencing and vertical layering can be combined. Move an object away to disconnect it.

Recording follows the arrangement of connected sound objects. When recording into an object in a horizontal sequence, preceding sounds can play before recording starts and following sounds can continue after recording ends. Vertically connected sounds can play while recording, making it possible to record in context.

Save sounds

Save sounds renders each stand-alone sound object or connected group that contains audio as a WAV file, plus a TXT file containing its titles, annotations, and object-image filenames.

Files use the title of the upper-left object. Separate groups create separate files. Sequential TXT sections are numbered and simultaneous sounds are separated by Mixed with.

Export and import a sketch

Export sketch saves the complete editable sketch as a ZIP file, including its title, sound objects, processed and source audio, active Signal tools, annotations, object images, background images, and their positions, sizes, and rotations.

Import sketch restores an exported sketch, including active Signal tools and background images. Select the ZIP file or drag it onto the button. Import replaces the current sketch.

Background images

Click the picture button to select an image, drag an image file from the computer onto empty canvas space, or drag an image directly from another browser window. Multiple background images can be used, and they remain behind sound objects and snap markers. An image dropped onto a sound object becomes that object’s annotation image instead.

Drag the image to move it. Use the bottom-right handle to resize proportionally, the top-right handle to rotate, and the × in the top-left corner to delete.

Background images, including their files, positions, proportional sizes, and rotations, are preserved when exporting and importing a sketch.

Opening Signal tools

Double-click a sound object outside editable fields to open Signal tools. Opening it stops playback. Double-click the pane outside its buttons to close it.

Active effects appear pressed. Click an active button again to remove it. Duration is recalculated after trimming or adding and removing reverberation.

Available processing

  • -3dB / +3dB: decrease or increase the sound level by 3 dB.
  • Trim start / Trim end: remove silence from the beginning or the end of a sound.
  • Reverse: play the sound backwards.
  • Random: randomize the playback order of sections of the sound.
  • Room / Hall / Church: add reverberation with different room sizes. Several reverbs can be combined.
  • Robot / Metal: apply different metallic modulation effects. Robot uses a triangle-wave ring modulation, while Metal combines several faster modulations with bright noise.
  • LPF / BPF / HPF: apply low-pass, band-pass, or high-pass filtering to emphasize different frequency ranges.

Processed audio is used for playback, saving, and sketch export.
