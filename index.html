How to use Sound Sketch

The microphone must be activated before sounds can be recorded. Click Enable microphone and allow microphone access in the browser. Alternatively, an existing audio file can be dragged and dropped directly onto an object’s recording button.

The canvas can be zoomed in and out using the mouse wheel. Right-click and drag to move around the canvas and focus on different parts of the workspace. Clicking the + button adds a new object. Clicking on empty space outside an object removes the current focus from text fields or annotations.

Each object contains a title, an annotation, and a sound. The title can be edited by clicking the title field and entering a new name. The annotation can contain text, an image, or both. Images can be dragged into an object either from the computer or from another browser window. When an image has been added, it covers the text annotation, but the annotation is displayed when hovering over the image. Double-click the image to edit the text annotation.

Sound can be recorded by pressing and holding Hold to record or drop audio file, then releasing the button when the recording is finished. An existing audio file can instead be dragged directly onto the same button. Once audio has been recorded or added, the button changes to Play, and the duration of the sound is displayed. The × button in the upper-right corner of an object deletes it.

Objects can be moved freely around the canvas. When two objects are brought close together, the object being moved snaps to the other object. Snapped objects are visually connected.

When objects are snapped horizontally, their sounds are played sequentially from left to right. Pressing Play on any object in the connected group plays the complete sequence. A sequence can contain as many objects as needed.

When objects are snapped vertically, their sounds are mixed and played simultaneously. Any number of sounds can be combined in this way. Vertical mixing and horizontal sequencing can also be combined. When a vertical group is followed by another object or group to its right, the next sound starts after the longest sound in the preceding vertical group has finished. Moving an object away from a connected group disconnects it and makes it a stand-alone object again.

The Save sounds button in the lower-right corner exports the work. For each stand-alone object or connected group, two files are downloaded:

  • a WAV file containing the sequenced and/or mixed audio;
  • a TXT file containing the object titles, annotations, and the filenames of any images that have been added.

The audio and text files use the title of the upper-left object in the group as their filename. If several independent objects or groups exist on the canvas, a separate WAV and TXT file is created for each. The browser may ask for permission to download multiple files, which must be allowed for all files to be saved.

The TXT file follows the same structure as the sound arrangement. Sequential sections are numbered, while annotations belonging to sounds that are mixed in parallel are separated by “Mixed with”.
